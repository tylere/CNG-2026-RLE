Speaker: Tyler Erickson
Time: 10:25 AM
Title: Cloud-Native Geospatial for Country-Scale Ecosystem Risk Assessment
Length: 20 Minutes
Room: Primrose A
Track 2: Cloud-Native Geo in Practice

The IUCN Red List of Ecosystems (RLE) is the global standard for assessing ecosystem risk — the ecological counterpart to the Red List of Threatened Species. An RLE assessment integrates spatial data at national scales, computes metrics like ecosystem extent, rate of decline, and area of occupancy, and produces a formal report meeting IUCN's rigorous criteria. Historically, assessors have done this with a patchwork of tools and ad hoc scripts that are difficult to share, reproduce, or maintain across teams. This talk describes the development of an open-source, cloud-native assessment workflow that assists in generating country-scale ecosystem assessments. The end result is a published static site displaying large-scale geospatial data interactively with no geospatial server required, and notebooks that show how to reproduce the results. This is made possible by cloud-native formats: GeoParquet and Cloud Optimized GeoTIFFs (COGs) served from object storage and rendered client-side using Lonboard. The system can also read and write geospatial data from Google Earth Engine. The assessment report and its interactive maps are published with static site hosting (e.g. GitHub Pages). Assessors develop their analysis in Jupyter notebooks. A document-as-code publishing pipeline renders those notebooks directly into the static site, so the code, narrative, and interactive visualizations are all version-controlled in one place and reproducible by anyone with access to the repository. The biggest challenge wasn't the geospatial computation, rather it was making an open source workflow that integrates many tools (geospatial data repositories, cloud compute, GitHub) easy to set up and configure. RLE assessors are typically ecologists and conservation scientists, not software engineers. Getting the workflow into their hands meant treating setup friction as a first-class problem: one-command environment installation using modern Python tooling (uv and pixi), a GitHub template repository that any assessor can fork to start a new country assessment, and a pre-structured report template with configuration files that separate science from code. Attendees will leave with an example of what cloud-native geospatial formats make possible at country scale — and honest lessons about where the tooling still falls short for non-technical users. https://iucnrle.org/ https://github.com/rle-assessment
